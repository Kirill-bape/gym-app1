# Форма — приложение для зала (прототип)

Мобильное приложение на Expo (React Native + TypeScript). Работает на Android и iPhone.
Все данные хранятся на самом телефоне, поэтому другу достаточно установить приложение, и у него будет свой профиль.

## Что умеет

- **Регистрация при первом запуске:** имя, фамилия, цель (сбросить вес / набрать мышцы / быть в форме), пол, возраст, рост, вес, желаемый вес, активность, сколько раз в неделю ходить в зал.
- **Калории:** норма в день по формуле Миффлина — Сан Жеора с учётом активности и цели (дефицит ~500 ккал для похудения, профицит ~300 для набора), белки/жиры/углеводы и прогноз, за сколько недель дойдёшь до желаемого веса.
- **Дневник питания:** добавить еду с калориями или в одно касание из списка популярных продуктов.
- **План тренировок на неделю:** строится из цели и числа дней (2–6). У каждого упражнения подходы × повторения, например «Жим штанги лёжа 4 × 12». Подходы отмечаются нажатием, прогресс недели считается автоматически и обнуляется по понедельникам.
- **Профиль:** записать текущий вес, посмотреть расчёт, изменить данные и цель.

## Как запустить на телефоне (самый быстрый способ)

Нужен компьютер с [Node.js](https://nodejs.org) (версия 20 или новее).

1. Установи на телефон приложение **Expo Go** из App Store или Google Play.
2. На компьютере в папке проекта:
   ```bash
   npm install
   npx expo start
   ```
3. В терминале появится QR-код. На Android отсканируй его в Expo Go, на iPhone — обычной камерой.
4. Телефон и компьютер должны быть в одной Wi-Fi сети. Если не подключается: `npx expo start --tunnel`.

## Как получить APK

**Через GitHub (без компьютера):** в репозитории уже есть сборка `.github/workflows/android-apk.yml`. После пуша в `main` GitHub сам собирает APK (около 15 минут) и выкладывает `forma.apk` в раздел Releases. Открой эту страницу с телефона, скачай и установи.

**Через Expo EAS (с компьютера):**
```bash
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview
```
В конце будет ссылка и QR-код на APK.

**Установка на Android:** открой скачанный `forma.apk`, разреши «Установку из неизвестных источников» для браузера или файлового менеджера и нажми «Установить».

Для iPhone APK не подходит: нужен аккаунт Apple Developer ($99 в год), `npx eas-cli build -p ios` и TestFlight.
