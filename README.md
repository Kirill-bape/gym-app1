# Форма — приложение для зала

Мобильное приложение на Expo (React Native + TypeScript). Работает на Android и iPhone.
Все данные хранятся на самом телефоне, поэтому другу достаточно установить приложение, и у него будет свой профиль.

## Что умеет

- **Регистрация при первом запуске:** имя, фамилия, цель (сбросить вес / набрать мышцы / быть в форме), пол, возраст, рост, вес, желаемый вес, активность и дни недели для зала.
- **Калории:** норма в день по формуле Миффлина — Сан Жеора с учётом активности и цели (дефицит ~500 ккал для похудения, профицит ~300 для набора), белки/жиры/углеводы и прогноз, за сколько недель дойдёшь до желаемого веса.
- **Калории по фото:** сфоткай тарелку, и нейросеть оценит вес каждой позиции, калории и БЖУ. Калории можно поправить перед записью в дневник. Нейросеть выбирается в профиле, есть бесплатные варианты (см. ниже).
- **Дневник питания:** добавить еду вручную, по фото или в одно касание из списка популярных продуктов. БЖУ за день считается по фото и быстрым продуктам.
- **План тренировок на неделю:** сам выбираешь дни (от 2 до 6), план строится под цель и число дней. У каждого упражнения подходы × повторения, например «Жим штанги лёжа 4 × 12». Подходы отмечаются нажатием, прогресс недели обнуляется по понедельникам. Дни можно поменять в любой момент на экране «Тренировки».
- **Техника упражнений:** нажми на упражнение, и откроется карточка: фото начала и конца движения, какие мышцы работают, пошаговая техника, частые ошибки, совет и кнопка «Видео с техникой на YouTube».
- **Профиль:** записать текущий вес, посмотреть расчёт, выбрать нейросеть для фото, изменить данные и цель.
- **Обновления:** на Android приложение само видит новую сборку в Releases и показывает на главной плашку «Вышла новая версия».

## Калории по фото: какую нейросеть выбрать

Фото уходит прямо из приложения в выбранную нейросеть, своего сервера у приложения нет. Нейросеть выбирается в приложении: Профиль → «Калории по фото». Ключи и адреса хранятся только на телефоне (в защищённом хранилище), в репозиторий и APK они не попадают.

| Вариант | Цена | Где работает |
|---|---|---|
| Ollama Cloud | бесплатно, с лимитом | везде, где есть интернет |
| Ollama на компьютере | бесплатно, без лимитов | дома, когда телефон в одной Wi-Fi сети с компьютером |
| Claude | около 1–3 центов за фото | везде, где доступен Anthropic API; самый точный |

API ChatGPT (OpenAI) бесплатно не работает: он оплачивается отдельно от подписки ChatGPT Plus, поэтому его в приложении нет.

### Ollama Cloud (бесплатно)

1. Зарегистрируйся на [ollama.com](https://ollama.com).
2. Открой [ollama.com/settings/keys](https://ollama.com/settings/keys), создай ключ и скопируй его.
3. В приложении выбери Ollama Cloud, вставь ключ и нажми «Проверить и сохранить». Приложение проверит ключ и покажет, сколько осталось бесплатного лимита и когда он обновится.

Модель по умолчанию `gemma4:31b`, она понимает фото. Размер бесплатного лимита Ollama не публикует, текущий остаток виден на [ollama.com/settings/usage](https://ollama.com/settings/usage). Один ключ можно вставить на несколько телефонов (например, родителям), но лимит у них будет общий.

### Ollama на своём компьютере (бесплатно, без лимитов)

1. Скачай на компьютере модель, которая понимает фото: `ollama pull gemma4`. Для слабого компьютера есть модель поменьше: `ollama pull gemma4:e2b`.
2. Разреши Ollama принимать запросы из Wi-Fi. Если в настройках приложения Ollama есть переключатель «Expose Ollama to the network», включи его. Иначе задай переменную окружения `OLLAMA_HOST=0.0.0.0:11434` и перезапусти Ollama ([инструкция для Windows, macOS и Linux](https://docs.ollama.com/faq)). На Windows: выйди из Ollama через значок в трее, в поиске Windows набери «переменные среды», открой переменные среды своей учётной записи, добавь `OLLAMA_HOST` со значением `0.0.0.0:11434` и запусти Ollama из меню «Пуск».
3. Если Windows спросит про брандмауэр, разреши доступ в частных сетях.
4. Узнай адрес компьютера в сети: на Windows команда `ipconfig`, строка «IPv4-адрес», например `192.168.1.5`.
5. В приложении выбери «Ollama на компьютере», введи адрес, нажми «Найти модели», выбери модель и «Сохранить».

Работает, только пока компьютер включён и телефон в той же Wi-Fi сети. Первое фото после запуска считается дольше: модель загружается в память. Маленькие модели на компьютере обычно ошибаются чаще облачных, поэтому калории перед записью стоит проверить. Чтобы приложение могло ходить на компьютер по обычному HTTP, в `app.json` включён `usesCleartextTraffic` (плагин `expo-build-properties`).

### Claude (платно, точнее всего)

1. Зарегистрируйся в [Claude Console](https://platform.claude.com/settings/keys).
2. В разделе Billing пополни баланс. Одно фото стоит примерно 1–3 цента.
3. В разделе API Keys создай ключ.
4. В приложении выбери Claude, вставь ключ и нажми «Проверить и сохранить».

Используется модель Claude Opus 5.5 с включённым резервным переключением на другую модель, если основная перегружена. Anthropic API работает не во всех странах.

## Как запустить на телефоне (самый быстрый способ)

Нужен компьютер с [Node.js](https://nodejs.org) (версия 20 или новее).

1. Установи на телефон приложение **Expo Go** из App Store или Google Play.
2. На компьютере в папке проекта:
   ```bash
   npm install
   npx expo start
   ```
3. В терминале появится QR-код. На Android отсканируй его в Expo Go, на iPhone — обычной камерой.
4. Телефон и компьютер должны быть в одной Wi-Fi сети. Если не подключается: `npx expo start --tunnel`.

## Как получить APK

**Через GitHub (без компьютера):** в репозитории уже есть сборка `.github/workflows/android-apk.yml`. После пуша в `main` GitHub сам собирает APK (около 15 минут) и выкладывает `forma.apk` в раздел Releases как «сборку N». Открой эту страницу с телефона, скачай и установи. Новая сборка ставится поверх старой, данные сохраняются (все сборки подписаны одним ключом, `versionCode` = номер сборки). APK собирается только для ARM-процессоров, это все современные телефоны.

**Через Expo EAS (с компьютера):**
```bash
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview
```
В конце будет ссылка и QR-код на APK.

**Установка на Android:** открой скачанный `forma.apk`, разреши «Установку из неизвестных источников» для браузера или файлового менеджера и нажми «Установить».

Для iPhone APK не подходит: нужен аккаунт Apple Developer ($99 в год), `npx eas-cli build -p ios` и TestFlight.

## Структура

```
App.tsx                      нижнее меню и переключение экранов
app.config.js                versionCode из номера сборки
src/calc.ts                  калории, БЖУ, прогноз
src/plan.ts                  план тренировок по выбранным дням
src/exercises.ts             техника упражнений: шаги, ошибки, советы, фото
src/ai/                      калории по фото: выбор нейросети (config), Ollama, Claude, общий формат ответа (schema)
src/photo.ts                 камера/галерея, сжатие фото до 1024 px
src/update.ts                проверка новой сборки в GitHub Releases
src/store.tsx                хранение данных на телефоне
src/secrets.ts               настройки нейросети и ключи в защищённом хранилище
src/components/              DayPicker, ExerciseSheet, FoodPhoto, AiSettingsCard, UpdateBanner, ui
src/screens/                 Onboarding, Home, Nutrition, Workouts, Profile
src/theme.ts                 цвета и шрифты (сюда переносим дизайн из Stitch)
assets/exercises/            фото упражнений
```
