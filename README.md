# Форма — приложение для зала

Мобильное приложение на Expo (React Native + TypeScript). Работает на Android и iPhone.
Все данные хранятся на самом телефоне, поэтому другу достаточно установить приложение, и у него будет свой профиль.

## Что умеет

- **Регистрация при первом запуске:** имя, фамилия, цель (сбросить вес / набрать мышцы / быть в форме), пол, возраст, рост, вес, желаемый вес, активность и дни недели для зала.
- **Калории:** норма в день по формуле Миффлина — Сан Жеора с учётом активности и цели (дефицит ~500 ккал для похудения, профицит ~300 для набора), белки/жиры/углеводы и прогноз, за сколько недель дойдёшь до желаемого веса.
- **Калории по фото:** сфоткай тарелку, и ИИ Claude оценит вес каждой позиции, калории и БЖУ. Калории можно поправить перед записью в дневник. Нужен свой ключ Anthropic API (см. ниже).
- **Дневник питания:** добавить еду вручную, по фото или в одно касание из списка популярных продуктов. БЖУ за день считается по фото и быстрым продуктам.
- **План тренировок на неделю:** сам выбираешь дни (от 2 до 6), план строится под цель и число дней. У каждого упражнения подходы × повторения, например «Жим штанги лёжа 4 × 12». Подходы отмечаются нажатием, прогресс недели обнуляется по понедельникам. Дни можно поменять в любой момент на экране «Тренировки».
- **Техника упражнений:** нажми на упражнение, и откроется карточка: фото начала и конца движения, какие мышцы работают, пошаговая техника, частые ошибки, совет и кнопка «Видео с техникой на YouTube».
- **Профиль:** записать текущий вес, посмотреть расчёт, подключить ключ ИИ, изменить данные и цель.
- **Обновления:** на Android приложение само видит новую сборку в Releases и показывает на главной плашку «Вышла новая версия».

## Калории по фото: ключ Anthropic API

Фото отправляется напрямую из приложения в Anthropic API (модель Claude Opus 5.5, с включённым резервным переключением на другую модель, если основная перегружена). Ключ вводится в приложении и хранится только на телефоне (в защищённом хранилище), в репозиторий и APK он не попадает.

1. Зарегистрируйся в [Claude Console](https://platform.claude.com/settings/keys).
2. В разделе Billing пополни баланс. Одно фото стоит примерно 1–3 цента.
3. В разделе API Keys создай ключ.
4. В приложении: Профиль → «Калории по фото» → вставь ключ → «Проверить и сохранить».

Anthropic API работает не во всех странах. Чтобы друзьям не нужно было заводить свой ключ, следующим шагом можно поставить небольшой сервер-прокси с одним общим ключом.

## Как запустить на телефоне (самый быстрый способ)

Нужен компьютер с [Node.js](https://nodejs.org) (версия 20 или новее).

1. Установи на телефон приложение **Expo Go** из App Store или Google Play.
2. На компьютере в папке проекта:
   ```bash
   npm install
   npx expo start
   ```
3. В терминале появится QR-код. На Android отсканируй его в Expo Go, на iPhone — обычной камерой.
4. Телефон и компьютер должны быть в одной Wi-Fi сети. Если не подключается: `npx expo start --tunnel`.

## Как получить APK

**Через GitHub (без компьютера):** в репозитории уже есть сборка `.github/workflows/android-apk.yml`. После пуша в `main` GitHub сам собирает APK (около 15 минут) и выкладывает `forma.apk` в раздел Releases как «сборку N». Открой эту страницу с телефона, скачай и установи. Новая сборка ставится поверх старой, данные сохраняются (все сборки подписаны одним ключом, `versionCode` = номер сборки). APK собирается только для ARM-процессоров, это все современные телефоны.

**Через Expo EAS (с компьютера):**
```bash
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview
```
В конце будет ссылка и QR-код на APK.

**Установка на Android:** открой скачанный `forma.apk`, разреши «Установку из неизвестных источников» для браузера или файлового менеджера и нажми «Установить».

Для iPhone APK не подходит: нужен аккаунт Apple Developer ($99 в год), `npx eas-cli build -p ios` и TestFlight.

## Структура

```
App.tsx                      нижнее меню и переключение экранов
app.config.js                versionCode из номера сборки
src/calc.ts                  калории, БЖУ, прогноз
src/plan.ts                  план тренировок по выбранным дням
src/exercises.ts             техника упражнений: шаги, ошибки, советы, фото
src/ai/                      оценка калорий по фото через Claude
src/photo.ts                 камера/галерея, сжатие фото до 1024 px
src/update.ts                проверка новой сборки в GitHub Releases
src/store.tsx                хранение данных на телефоне
src/secrets.ts               ключ API в защищённом хранилище
src/components/              DayPicker, ExerciseSheet, FoodPhoto, AiKeyCard, UpdateBanner, ui
src/screens/                 Onboarding, Home, Nutrition, Workouts, Profile
src/theme.ts                 цвета и шрифты (сюда переносим дизайн из Stitch)
assets/exercises/            фото упражнений
```
